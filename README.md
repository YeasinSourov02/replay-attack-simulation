## Description
This project demonstrates a Replay Attack using Python Socket Programming.
 
The vulnerable server processes duplicate transfer requests.
 
The secure server prevents replay attacks using unique request IDs and replay detection.
 
## Prevention Technique
Request ID validation using a processed request list.
